# Priya Malik — page images

Images for the Priya Malik typewriter landing page. The Framer component
loads them from
`https://cdn.jsdelivr.net/gh/infomahakchowdhury-create/priya-malik-assets@main/`.

They are generated by `priya-malik/tools/build_assets.py` in the
`mumbai-fringe` repo. Replace them from that repo's `priya-malik/assets/`
folder; keep the file names.
